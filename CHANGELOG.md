# Changelog

All notable changes to the **Briskli** extension will be documented in this file.

## [0.1.0] - 2025-12-31

### Initial Release 🚀
- **Prompt Vault**: Advanced organization for all your AI prompts.
- **Turbo Mode**: Ctrl+Click injection into Cursor, Copilot, Cody, and others.
- **AI Generator**: Persona-driven prompt creation with Role, Intent, and Difficulty settings.
- **Predictive Suggestions**: Real-time analysis of the active file to suggest the best prompts.
- **Multi-Select Mode**: Efficient batch management of prompt cards.
- **Premium UI**: Modern, glassmorphic design system for VS Code sidebar.
